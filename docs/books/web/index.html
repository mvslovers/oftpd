OFTPD (oftpd) for MVS 3.8j

The OFTP (ODETTE File Transfer Protocol) server for MVS 3.8j: a monitor that runs as a started task, the OFTP utility for TSO and batch, and an ISPF dialog. Two books describe OFTPD. Both are Drafts: chapters still to be written say so.
